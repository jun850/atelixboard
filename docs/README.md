# Boardy product and engineering docs

Choose the implementation package for the task:

| Package | Read it for |
| --- | --- |
| [Idea → handoff → detail](idea-to-handoff/README.md) | Workspace vision, ownership handoffs, project files and supporting documents |
| [Agentic board](agentic-board/README.md) | Connected LLMs, user-selected models, editable templates, UI prototypes, frontend/backend/companion work and end-to-end QA |

Each package includes its own vision, PRD and implementation guidance. Agents should start at the package index and follow its reading order. Canvas PRD templates are visual artifacts; formal handoff document creation remains a separate workflow.

This documentation describes proposed product directions grounded in the current Boardy implementation. It does not mean the described APIs, tables, permissions, AI integrations, desktop companion or Docmost integration are deployed.
