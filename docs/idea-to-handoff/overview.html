Build the useful loop first.

Start with secure projects and a handoff that survives retries, reloads, and changed access. Add Markdown export before making document generation depend on an external service.

Use Docmost Community with a small open-source bridge we maintain. Reuse native document services and verify account/space access. No enterprise API keys or paid templates are required.

Privacy follows the context.

Keep the original board browser-encrypted. Show exactly which selected content will become server-readable project context before publishing it. Never pass the board key to the workflow service.
